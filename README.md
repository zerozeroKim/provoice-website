# React Design System Starter

React + TypeScript + CSS Modules + Vite로 만든 작은 웹사이트용 디자인 시스템 예제입니다.

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.

## 구조

- `tokens`: 색상, 간격, 타이포그래피, 모서리, 그림자 값
- `styles`: CSS 변수, 리셋, 전역 스타일
- `primitives`: Box, Stack, Text
- `components`: Button, Input, Select, Checkbox, Badge, Card, Modal
- `patterns`: FormField처럼 여러 UI 요소를 조합한 패턴
- `pages`: 실제 화면
